## 已复现的历史错误

方法01 对 `abba` 输出 `2`，最长回文子串的正确长度是 `4`。原因是直接对所有长度二分时，“存在长度为 len 的回文串”不具有逐长度单调性：长度 4 存在，长度 3 可以不存在。此稿还保留较大的哈希数组。方法01 原样保留为历史尝试；方法02 为 Manacher 方案。
