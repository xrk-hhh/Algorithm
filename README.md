# Algorithm · 算法竞赛代码与知识库

整理洛谷、蓝桥杯、牛客、AtCoder 的练习、模板、训练赛，以及个人网站 starlight 的算法竞赛文章。默认使用 **GNU C++14**，早期 C 练习保留 C11。

收录 **847 份原始源码**（672 C++、175 C）、**4 份远端历史差异版本**、**32 篇网站算法文章**（含知识地图）、**8 篇工作区题解**和推荐题单。整理出的 **43 个知识分类**提供核心概念、复杂度、易错点和代码链接；未能可靠判定的题目明确标为“待细分”或候选分类。

整文件注释中保存的实现已按方法恢复：**51 份多方法原稿**分别提供对照说明；共生成 **870 个独立方法、接口或片段**。原稿完整保留，恢复版记录来源与原文行号。870 个恢复单元与32份直接源码均通过 C++14/C11 语法检查，历史尝试和性能问题另作说明，语法通过不代表在线评测 AC。
