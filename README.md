## 使用说明

每份源码是独立题目或学习记录。保留原有注释、未完成稿和历史错误；全注释文件不能直接当成可运行解答。“候选”专题只是辅助检索，应以题解和完整实现核对。语法检查与在线评测正确性分开记录。

只提交源代码、Markdown 和必要 Git 规则；可执行文件、工程缓存、CPH 文件、输入输出文件、PDF/PPTX 和压缩包均已过滤。网站文章插图引用原 starlight 仓库的固定提交，需要联网显示。
