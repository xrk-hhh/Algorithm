## 对拍说明

`对拍/duipai.cpp` 是原 Windows 对拍驱动，通过 `system` 调用编译器和 `fc`，默认无限循环；仓库仅保存源码，未自动执行该驱动。`std.cpp` 名称表示当时的候选实现，不代表已证明正确。原实现存在对 `lower_bound` 返回 end 的解引用，以及子段和用 int 可能溢出等检查点，使用前需修复。
