# 数论与组合数学

**核心：整除结构与模运算。**

欧几里得 O(log n)，快速幂 O(log k)，线性筛 O(n)；组合计数先判断模数条件。

常见检查点：模逆元存在需要互质；乘法溢出，负数取模，1 和 0 的特殊情况。
